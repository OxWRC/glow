# Demo Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a deployment be provisioned as a public demo (fictional seed data, role-picker login, banner with login details and a reset button), with demo mode impossible to switch on for an existing real deployment.

**Architecture:** The existing dev auth bypass is renamed `DEMO_MODE` and becomes the single switch. The API gains `routers/demo.py` (`/demo/login`, `/demo/info`, `/demo/reset`) backed by a shared `seed_demo()` that `glow-init` also runs. The dashboard renders a `<details>` banner in `Layout`. The deploy tool carries `demo_mode` from CLI/GUI through Terraform into `/etc/glow-runner.env`, and `activate-stack.sh` adds a `compose.demo.yml` overlay.

**Tech Stack:** Python 3.12 / FastAPI / SQLAlchemy / click / pytest (api, deploy/aws); React + React Router + Vitest + Storybook + MSW (dashboard); Terraform; bash; docker compose.

**Spec:** `docs/superpowers/specs/2026-10-05-demo-mode-design.md` — read it before starting any task.

## Review Focus

1. **Update of a demo deployment** — `update()` re-runs userdata, which rewrites `/etc/glow-runner.env`; if `GLOW_DEMO_MODE` isn't passed it silently becomes a non-demo box with seed data. Expect: update preserves the mode read from Terraform outputs. (Task 5 test.)
2. **Pre-feature deployment provisioned again** — state has no `demo_mode` output. Expect: treated as `false`; `--demo` on it is refused, plain provision proceeds. (Task 5 test.)
3. **`glow-api demo reset` on a real deployment** — expect refusal with non-zero exit when `DEMO_MODE` is off, before touching the DB. (Task 2 test.)
4. **Reset while a visitor is logged in** — expect the old token to get 401 and the dashboard to land on login, not crash. (Task 3 API test; Task 4 story asserts navigation/status.)
5. **`/demo/info` fails or returns no schools** — expect the banner still renders, shows an error line or an empty-list message, and Reset still works. (Task 4 stories.)
